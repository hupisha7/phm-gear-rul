## W5 · 傅里叶变换与频谱

### 概念（必须能自己讲出来）

| 概念 | 要点 |
|---|---|
| 时域 vs 频域 | 同一信号的两种表示；时域看不出周期成分，频域能 |
| DFT / FFT | FFT 是 DFT 的快速算法，结果一样，复杂度 O(N²) → O(N log N) |
| 采样定理 | Fs > 2 × f_max，否则混叠（aliasing） |
| 奈奎斯特频率 | Fs/2 = **50,000 Hz**，超过这个频率的成分会折叠回来 |
| **频率分辨率** | **Δf = Fs / N**；想分辨两个靠近的频率，必须加长采样时间 |
| 频谱泄漏 | 信号两端不连续 → 能量"漏"到邻近频点 |
| 窗函数 | Hanning/Hamming 让两端平滑，减少泄漏；代价是主瓣变宽（分辨率略降） |

### 读什么

1. **3Blue1Brown《But what is the Fourier Transform?》** —— 先建立直觉（40 分钟）
2. **《The Scientist and Engineer's Guide to DSP》**（免费 stevenwsmith.com）
   - 第 8 章 The Discrete Fourier Transform
   - 第 9 章 Applications of the DFT
   - 第 14 章 Introduction to Digital Filters（只看窗函数那部分）
3. 遇到不确定就查 NumPy 的 `np.fft` 官方文档

## W6 · 齿轮运动学与边频带

### 概念

| 概念 | 要点 |
|---|---|
| 转频 f_r | 轴的旋转频率（Hz）= 转速（rpm）/ 60 |
| **啮合频率 GMF** | **GMF = 齿数 × 转频**；一对啮合齿轮的 GMF 相同 |
| 高次谐波 | 2×GMF、3×GMF…… 齿廓偏差和啮合刚度变化会让高次谐波很强 |
| **调制** | 局部损伤的齿每转一次经过啮合区一次 → 给啮合信号"打拍子" |
| **边频带** | 调制在频谱上表现为 **GMF ± k×f_转** 处的一系列峰 |

### 关键参数（背下来）

| | 干摩擦 | 润滑 |
|---|---|---|
| 输入轴（小齿轮 19 齿） | 10 Hz | 16 Hz（实测 15.99） |
| 输出轴（大齿轮 52 齿） = 输入 × 19/52 | 3.654 Hz | 5.846 Hz |
| **GMF = 19 × 输入转频** | **190 Hz** | **304 Hz** |

### 读什么

1. **readme 里第一篇论文**：Feng et al., MSSP 150 (2021):107258
   《Use of cyclostationary properties of vibration signals to identify gear wear mechanisms and track wear evolution》
   —— 重点看它对边频带和循环平稳的论述
2. 任意一篇《齿轮故障诊断》综述，弄懂 AM/FM 调制模型

### 代码任务 `src/w6_gear_kinematics.py`

## W7 · 时域指标与趋势分析

### 概念

| 指标 | 公式要点 | 对什么敏感 |
|---|---|---|
| RMS（均方根） | √(mean(x²)) | 能量总量；**磨损后期明显上升** |
| 峰值 | max(\|x\|) | 冲击 |
| 峰峰值 | max − min | 冲击幅度 |
| **峭度 Kurtosis** | E[(x−μ)⁴] / σ⁴ | **冲击性**；早期磨损更敏感（健康≈3） |
| **峰值因子 Crest Factor** | 峰值 / RMS | 冲击的相对强度 |
| 裕度因子 Clearance Factor | 峰值 / (mean(√\|x\|))² | 早期故障 |
| 波形因子 Shape Factor | RMS / mean(\|x\|) | 波形变化 |

**为什么峭度比 RMS 更早发现异常**：RMS 反映总能量，早期磨损对总能量贡献很小；峭度只对"尖峰"敏感，早期点蚀产生的冲击会立刻拉高峭度。

### 代码任务 `src/w7_time_features.py`

**任务 1 · 实现 6 个指标**（不许调现成函数，除 `np.sqrt/mean/max`）

**任务 4 · 排出最单调的指标**

## W8 · 包络解调

### 概念

| 概念 | 要点 |
|---|---|
| 调制 | 载波（GMF 附近的高频振动）被转频"调幅" |
| **包络** | 载波振幅随时间变化的曲线 = 损伤的"指纹" |
| **Hilbert 变换** | 把实信号变成解析信号，取模就得到包络 |
| 带通滤波 | **必须先带通到载波频带**（如 GMF ± 20 Hz），否则包络无意义 |
| **包络谱** | 对包络再做 FFT，损伤频率（转频及其谐波）会清晰出现 |

**为什么需要包络**：直接看频谱时，损伤特征被淹没在 GMF 的高幅值里；包络谱把"损伤频率"单独提出来，一眼就能看出转频的倍数关系。

### 代码任务 `src/w8_envelope.py`

**任务 1 · 基本包络分析**
```
原始信号
  → 带通滤波（GMF ± 20 Hz）   ← scipy.signal.butter + filtfilt
  → Hilbert 变换              ← scipy.signal.hilbert
  → 取模得到包络
  → 对包络做 FFT              ← 包络谱
```

**任务 2 · 对比健康 vs 退化**

- 把两条包络谱画在同一张图上

**任务 3 · 提取特征**

- 对 20 个文件各算一遍，画趋势图

### 产出

- `results/w8_envelope_trend.png`（包络特征随时间的趋势）

## 常见坑

| 坑 | 表现 | 解决 |
|---|---|---|
| 忘了 detrend | 频谱 0 Hz 处一根巨大的峰 | 先 `x - x.mean()` |
| 没加窗 | 频谱到处是"裙边" | 加 `np.hanning(N)` |
| 横轴用 Hz 但没除以 N | 频率全错 | `f = np.fft.rfftfreq(N, 1/Fs)` |
| 只看实部 | 频谱不对称、信息缺失 | 用 `np.abs()` 取模 |
| 带通截止频率超过奈奎斯特 | `butter` 报错 | 归一化：`Wn = f / (Fs/2)` |
| 数据太长导致内存爆 | 20 个文件 × 110 万点 × 2 通道 | 分块处理，或先用前 1 秒 |
| 用 dB 看早期磨损 | 变化被压平看不出来 | 初学阶段用线性幅度 |
