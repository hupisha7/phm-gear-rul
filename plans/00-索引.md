## 你的数据速查表（贴在显示器旁边）

### 试验参数

| 项目 | 干摩擦 | 润滑 |
|---|---|---|
| 输入轴转速 | 10 Hz（设定） | 16 Hz（设定） |
| 制动载荷 | 5 Nm | 20 Nm |
| 润滑 | 无 | 油浴（146 mm²/s） |
| 试验时长 | ~2 h 22 min | ~67 h 14 min |
| 文件数 | 10 | 10 |
| 时间跨度 | 00h06m → 02h22m | 00h00m → 67h14m |

### 齿轮

| 参数 | 值 |
|---|---|
| 小齿轮齿数 | **19** |
| 大齿轮齿数 | **52** |
| 传动比 | 19/52 = **0.3654** |

### 关键频率（**必须背下来**）

| | 干摩擦 | 润滑 |
|---|---|---|
| 啮合频率 GMF | **190 Hz** | **304 Hz** |
| 输出轴转频 | 3.654 Hz | 5.846 Hz |

> 实测反推：润滑工况输入轴实际 **15.99 Hz**（不是标称的 16 Hz），GMF ≈ 303.8 Hz

### 传感器

| 符号 | 类型 | 说明 |
|---|---|---|
| `vib1` | B&K 4396 加速度计 | 灵敏度 **10.0** mV/(m/s²) |
| `vib2` | B&K 4394 加速度计 | 灵敏度 **1.0** mV/(m/s²)（比 vib1 低 10 倍） |
| `tacIN` | 转速计 | **1 脉冲/转**，装在**输入轴** |
| `encOUT` | 编码器 | **1000** 脉冲/转（干）**512**（润），装在**输出轴** |
| `Fs` | 采样率 | **100,000 Hz** |

### 信号基本量

| 量 | 值 | 算法 |
|---|---|---|
| 每文件点数 | 1,100,000 | 11 s × 100 kHz |
| **频率分辨率 Δf** | **0.0909 Hz** | Fs / N = 100000 / 1100000 |
| 奈奎斯特频率 | 50,000 Hz | Fs / 2 |
| 你的论文窗口大小 | 22,000 点 | 1,100,000 / 50 |
