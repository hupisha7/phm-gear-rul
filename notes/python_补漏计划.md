# Python 补漏计划（以用带学 · 4 周 · 每天 30 分钟）

> 起因：你反馈"Python 基础语法有点弱"
> 原则：**不停下 PHM 项目去学 Python。两条线并行，学到的语法立刻用在项目里。**

---

## 0. 先破一个误区

| ❌ 错误做法 | ✅ 正确做法 |
|---|---|
| 先花 3 个月"学完 Python"，再做项目 | 学一个点，马上在项目里用一次 |
| 看视频看到懂为止 | **把代码敲一遍**（看 ≠ 会） |
| 从"变量是什么"开始系统学 | 先做诊断，只补**你确实不会的**那部分 |
| 追求"掌握全部语法" | 追求"能读懂 + 能写出自己要的东西" |

**为什么？** 因为教程里 70% 的内容你做 PHM 用不上（装饰器元编程、异步、多进程……）。你现在的瓶颈不是"Python 学得不够多"，而是"**常用那 20% 不熟练**"。

## 1. 第一步：做诊断（20 分钟，今天做完）

**下面 15 道题，每题限 2 分钟。能独立写出来就打 ☑，写不出来就打 ☐。**

不许查资料、不许问 AI。**打 ☐ 的那几道，就是你的学习清单。**

把结果记在 `notes/python_selftest.md`。

### A 组 · Python 基础语法

- ☐ **1** 用**列表推导式**生成 1–100 中所有偶数的平方
- ☐ **2** 写一个函数 `minmax(lst)`，返回列表的最大值和最小值（**不许用 `max()` / `min()`**）
- ☐ **3** 写一个函数，带一个默认参数，然后调用它两次（一次传参、一次用默认值）
- ☐ **4** 用 f-string 打印：`Lubricated-00h00m.mat 的 RMS 是 0.0282`（RMS 保留 4 位小数）
- ☐ **5** 用 `dict` 统计一个列表里每个元素出现的次数

### B 组 · 常用工具（写代码时天天用）

- ☐ **6** 用 `enumerate` 遍历列表，同时拿到序号和值
- ☐ **7** 用 `zip` 同时遍历两个列表
- ☐ **8** 有一个字典列表，按其中某个键排序（`sorted(..., key=...)`）
- ☐ **9** 用 `try / except` 处理 `int("abc")` 抛出的异常
- ☐ **10** 用 `with open(...)` 读一个文本文件，逐行打印

### C 组 · NumPy（**比 Python 语法本身更重要**）

- ☐ **11** 创建形状 `(3, 4)` 的全零数组，把第 2 行全部设为 1
- ☐ **12** 形状 `(5,)` 的数组加一个标量，结果形状是什么？
- ☐ **13** 对形状 `(3, 4)` 的数组，`np.sum(a, axis=0)` 和 `np.sum(a, axis=1)` 分别得到什么形状？
- ☐ **14** `a[a > 0]` 是什么意思？
- ☐ **15** `a.reshape(2, -1)` 里的 `-1` 是什么意思？

### 判读

| 打 ☐ 的数量 | 结论 | 怎么学 |
|---|---|---|
| 0–2 个 | 你比自己以为的强 | 直接做 PHM 项目，缺什么补什么 |
| 3–6 个 | 典型状态 | 按下面 4 周计划走 |
| 7 个以上 | 需要系统补一轮 | 按 4 周计划走，但每天加到 1 小时 |

**注意：C 组（NumPy）比 A、B 组更重要。** 因为 PHM 里 90% 的代码是数组运算，Python 语法只是外壳。

## 2. 必须掌握的子集（就这些，不多学）

### Python 语法（够用即可）

```
变量与类型      int / float / str / bool / list / dict / tuple / set
运算符          + - * / // % **  以及 and or not in
控制流          if / elif / else、for、while、break / continue
函数            def、参数、默认值、return、多个返回值
列表推导式      [f(x) for x in xs if cond]        ← 极其重要
字典操作        d[k] / d.get(k, default) / d.items()
字符串          f"{x:.4f}"、split / join / strip / replace
异常            try / except / raise
文件            with open(...) as f
模块            import / from ... import ...
类（基础）      class、__init__、self、方法         ← 为了后面写 nn.Module
常用内置        len / range / enumerate / zip / sorted / sum / abs / round
类型注解        def f(x: int) -> float:            ← 看懂就行
```

### NumPy（这才是重点）

```
创建            np.array / zeros / ones / arange / linspace / random
形状            .shape / .reshape / .T / .squeeze / .flatten
索引切片        a[0] / a[1:3] / a[:, 0] / a[a > 0]（布尔索引）
广播            形状不同怎么自动对齐              ← 核心中的核心
axis            axis=0 是"沿行方向压掉"，axis=1 是"沿列方向压掉"  ← 核心中的核心
运算            + - * / 是逐元素；@ 是矩阵乘法    ← 别搞混
聚合            sum / mean / std / max / min，都带 axis
拼接             concatenate / stack
```

**只要这两块，你就能读懂并写出 90% 的 PHM 代码。**

## 5. 怎么正确地用 AI（这条很重要）

你 AI 用得很熟，但**用法要改**。学 Python 阶段，AI 应该是**出题人和批改人**，不是写手：

| ✅ 这样用 | ❌ 不要这样用 |
|---|---|
| "给我出 5 道列表推导式的题，由易到难" | "帮我写一个列表推导式实现 XX" |
| 贴**自己写的**代码："这样写对吗？有没有更简洁的？" | 贴报错然后让 AI 改你的代码 |
| "为什么 `a * b` 和 `a @ b` 结果不一样？" | "解释一下这段代码"（整段） |
| "这个报错 `IndexError: list index out of range` 一般什么原因？" | — |

**判据：AI 给的任何代码，你都必须能关掉 AI 自己重写一遍。**

## 6. 三条纪律

1. **每天 30 分钟不能断。** 断了不补，第二天继续。断三天就重新开始了。
2. **必须敲代码，不能只看。** 看教程会产生"我懂了"的幻觉，敲一遍才知道不会。
3. **报错就是老师。** 遇到报错先读报错信息最后一行——它会告诉你文件、行号、原因。
