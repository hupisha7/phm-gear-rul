## W10 · 绝对传动误差（ATE）

### 为什么用传动误差

齿轮磨损 → 齿廓改变 → **实际输出轴角度偏离理想值**。

```
理论输出角 = 输入轴角 × (19/52)
传动误差   = 实际输出角 − 理论输出角
```

**它是最强的健康指标**，因为：
- 它是**物理量**，不是时间
- 它**随磨损单调增大**，天然可作 HI
- 它有论文背书：readme 第二篇 **Chin et al., MSSP 146 (2021):107070**《绝对传动误差：一个评估齿轮磨损的简单新工具》

### 先搞懂两个通道

| 通道 | 是什么 | 怎么用 |
|---|---|---|
| `tacIN` | 转速计，**1 脉冲/转**，输入轴 | 每个脉冲 = 输入轴转了 1 圈 → 提供**输入轴角度** |
| `encOUT` | 编码器，**1000**（干）/**512**（润）脉冲每转，输出轴 | 提供**输出轴角度** |

**难点：`encOUT` 是什么形式的信号？**
- 值域是 ±2.9 左右，不是 0/5V 的方波 —— 所以**不是标准 TTL 增量编码器输出**
- 可能是：正弦/余弦编码器、或者 AC 耦合后的脉冲
- **必须先画出来看**，判断是脉冲串、正弦波，还是别的

### 代码任务 `src/w10_transmission_error.py`

**任务 1 · 先看图（这一步不能跳）**
- 画 `tacIN`、`encOUT` 各前 50,000 点的波形
- 放大到一个脉冲附近，看清脉冲形状
- 判断 `encOUT` 到底是什么信号

**任务 2 · 解码 tacIN 得到输入轴转角**
- 找脉冲位置（阈值 + 峰值检测）
- 每个脉冲对应角度增加 2π
- 两个脉冲之间做**线性插值**，得到每个采样点的输入轴转角 θ_in(t)

**任务 3 · 解码 encOUT 得到输出轴转角**
- 依赖任务 1 的判断结果
- 如果是脉冲计数：同上
- 如果是正弦/余弦：用 `arctan2` 解相位

**任务 4 · 算传动误差**
```
θ_in_expected_out = θ_in × (19/52)       # 理想输出角
ATE(t) = θ_out(t) − θ_in_expected_out(t)
```
- 去掉线性趋势（`scipy.signal.detrend`）
- 算 ATE 的 **RMS** 作为该文件的特征

**任务 5 · 对 20 个文件算一遍**
- 画 ATE-RMS 随运行时刻的趋势图

### 验收

2. 为什么传动误差能反映齿轮磨损？（用齿廓变化解释）

### 如果 ATE 算不出来怎么办

**别死磕。** `encOUT` 信号形式不明时，可以先用**替代指标**：

| 替代 | 做法 |
|---|---|
| 转速波动 | 从 `tacIN` 脉冲间隔算瞬时转频的方差 |
| 输出轴转速波动 | 从 `encOUT` 算输出轴瞬时转速的波动 |

**任何"从编码器/转速计提取的、随磨损变化的量"都比"时间"强。**

## W11 · 特征筛选（PHM 标准三准则）

### 概念

PHM 领域筛健康指标有三个公认准则：

| 准则 | 含义 | 怎么算 |
|---|---|---|
| **单调性 Monotonicity** | HI 是否一直朝一个方向走 | `Mon = |Σ sign(ΔHI)| / (n−1)` 或 `|Spearman|` |
| **趋势性 Trendability** | HI 和时间的关系有多强 | 和时间的相关系数（Pearson / Spearman） |
| **鲁棒性 Robustness** | 对噪声和异常值是否稳定 | 平滑前后的一致性，或 1 − 变异系数 |

**最终 HI 应该是这三者的加权组合。**

### 代码任务 `src/w11_feature_selection.py`

**任务 1 · 收集所有候选特征**

把阶段 2 和 W10 算出的特征汇总成一张表：

| 类别 | 特征 |
|---|---|
| 时域（W7） | RMS、峰值、峰峰值、峭度、峰值因子、裕度因子 |
| 包络（W8） | 转频 1×/2×/3× 幅值、包络 RMS |
| 频域 | GMF 幅值、2GMF、3GMF、边频带能量比 |
| 传动（W10） | ATE-RMS、转频波动 |
| 时频（W9，选做） | 小波包能量比 |

→ 总共 **12–18 个候选特征**

**任务 2 · 实现三个准则**
- 对每个特征、每个工况，算 Mon / Trend / Rob
- 归一化到 0–1

**任务 3 · 打分排序**
```
score = 0.4 × 单调性 + 0.4 × 趋势性 + 0.2 × 鲁棒性
```

**任务 4 · 挑出 Top 5**
- 两个工况分别排
- 观察：两个工况选出的特征一样吗？

### 产出

- `src/w11_feature_selection.py`
- `results/w11_feature_scores.csv`（特征 × 三准则 × 总分）
- `results/w11_top_features.png`（Top 5 的趋势图）

### 验收

1. 哪个特征得分最高？它在两个工况下都高吗？
2. 有没有"润滑单调但干摩擦不单调"的特征？为什么？
3. 单调性和趋势性有什么区别？（提示：一个单调下降的特征，趋势性可以是负的）

## W12 · 无监督健康指标构建

### 思路

**只用心最"健康"的数据**（`00h00m`）训练一个模型，让它学会"健康长什么样"；
之后每个文件的**重构误差**就是健康指标——越不健康，误差越大。

**这一步完全不需要任何标签。**

### 三种方法（选一种，推荐 A）

#### 方法 A · 自编码器重构误差（推荐）

```
输入：健康文件（00h00m）切出的窗口
训练：自编码器，目标是"输入 = 输出"
推理：把每个文件喂进去，算 MSE(输入, 输出) = HI
```

**网络要小**（你的数据量少）：
```
编码器: 输入(B, 2, L) → Conv1d → Conv1d → GAP → 低维向量
解码器: 低维向量 → Linear → 上采样 → ConvTranspose1d → 输出(B, 2, L)
```

#### 方法 B · 马氏距离

- 从健康文件算特征的均值向量 μ 和协方差 Σ
- 每个文件的 `HI = √((x−μ)ᵀ Σ⁻¹ (x−μ))`

#### 方法 C · 多特征 PCA 融合

- 对 Top 5 特征做标准化 → PCA → 取第一主成分作 HI

**建议：先做 B 或 C（简单、几行代码），跑通了再做 A。** 不要一上来就上神经网络。

### 代码任务 `src/w12_health_indicator.py`

**任务 1 · 先做最简单的（B 或 C）**
- 目标：**先拿到一条能画的曲线**

**任务 2 · 画 HI 曲线**

## W13 · 阈值定义与退化建模

### 概念

| 概念 | 要点 |
|---|---|
| 失效阈值 | **这是工程决策，不是事实**。三种定法见下 |
| 退化模型 | 指数模型 `HI(t) = a·exp(b·t)`、线性、幂律 |
| 维纳过程 | 带随机项的退化过程，能给出寿命分布 |
| 首预测时刻 FPT | HI 首次越过某个预警线的时刻 |

### 阈值的三种定法

| 方法 | 做法 | 适用 |
|---|---|---|
| **A（推荐）** | 取最后一个文件（试验结束、齿轮已严重磨损）的 HI 值 | 有 run-to-failure 数据时最自然 |
| B | 健康基线 + 3σ | 保守，适合在线监测 |
| C | 查论文里点蚀密度/表面轮廓对应的判据 | 最严谨，需要读文献 |

### 代码任务 `src/w13_degradation_model.py`

**任务 1 · 定义阈值**
- 用方法 A

**任务 2 · 拟合退化模型**
- 对 HI(t) 拟合指数模型：`scipy.optimize.curve_fit`
- 画拟合曲线叠加在原始 HI 上

**任务 3 · 外推得 RUL**

这是一个**重要的认知转变**，请仔细做：

```
对每一个时刻 t_i：
    用 t_0 ~ t_i 的数据拟合退化模型（只用过去，不能用未来！）
    外推到阈值 → 得到预测的失效时刻 t_fail
    RUL(t_i) = t_fail − t_i
```

**注意上面这行注释：只能只用过去的数据。** 这正是你毕设做错的地方——用了未来的信息（时间标签）来"预测"当前状态。

**任务 4 · 画 RUL 预测曲线**

- 叠加真实 RUL（由 HI 外推得到）作对比

## 这 5 周最容易犯的错

| 错 | 后果 | 预防 |
|---|---|---|
| 用 `current_hour` 当特征 | **又泄漏了** | 每写一行都问："这行用了未来信息吗？" |
| 随机划分 | 指标虚高 | 只按文件顺序划分 |
| 用全部数据拟合退化模型 | 泄漏 | 只用 t_i 之前的数据 |
| HI 不单调就往下走 | 后面全白做 | **死磕到单调为止** |
| 一上来就用神经网络做 HI | 调试困难 | 先用马氏距离/PCA，几行代码搞定 |
| 指标难看就改数据 | 自欺 | 记住：**难看的真实数字 > 好看假数字** |
